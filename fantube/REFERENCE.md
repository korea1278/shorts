# 레퍼런스 분석 (2026-10-08)

시니어 대상 가수 쇼츠 3편(20~36초)을 측정해 엔진과 대본 규칙에 반영한 기준이다.
크기는 1080x1920 기준.

## 화면
| 항목 | 레퍼런스 측정값 | 엔진 설정 (`make_short.py`) |
|---|---|---|
| 제목 판 | 맨 위 짙은 밤색 검정(30,20,20) 판, 높이 약 414px, 아래 모서리 둥글게 | `BG`, `PANEL_H`, `PANEL_R` |
| 제목 글자 | 2줄, 글자 높이 약 72px, 한 줄 12~15자, 폭 최대 약 90% | 시작 78pt, 최대 폭 990px |
| 제목 색 | 윗줄 흰색 / 아랫줄 노란색, 얇은 검은 테두리 + 그림자 | 테두리 3px + 흐린 그림자 |
| 폰트 | 둥근 굵은 고딕 | G마켓 산스 Bold |
| 사진 | 세로 사진이 화면 가득 (약 380~1830px), 약 2초마다 교체, 살짝 확대 | 장면마다 `images` 2장, 확대 1.06배 |
| 자막 | 사진 위 가운데(위에서 약 60%), 흰색 한 줄, 8~12자, 글자 높이 약 70px | `SUB_CENTER_Y=1140`, 12자, 66pt, 테두리 5px |
| 하단 | 짙은 띠 + 좋아요·구독·알림 버튼, 커서가 눌러 '구독됨'으로 바뀜 | 4초마다 반복 애니메이션 |

## 소리
| 항목 | 레퍼런스 측정값 | 엔진 설정 |
|---|---|---|
| 목소리 | 남성, 중간 높이(약 145Hz), 또박또박 뉴스 낭독 톤 | 24번 Hojin Lim (약 132Hz) |
| 빠르기 | 1초에 약 7.8글자 (공백 제외) | 일레븐랩스 speed 1.2 + 쉼 줄이기 → 약 7.7글자 |
| 문장 사이 쉼 | 0~0.6초, 대부분 거의 없음 | 0.15초 넘는 쉼은 0.1초로 |
| 배경음악 | 아주 작게, 목소리보다 약 20~30dB 낮게 | `bgm/`에 파일 없으면 잔잔한 화음을 직접 만들어 22dB 낮게 |
| 효과음 | 4~8초마다 짧고 맑은 소리 | 장면이 바뀔 때 '띵' |
| 최종 음량 | - | 유튜브 기준 -14 LUFS로 맞춤 |

## 대본 구조
- 첫 문장 = 제목을 그대로 읽는 궁금증 훅
- 연도·숫자로 사연 → "하지만" 반전 → 마무리
- 말투 "~는데요", "~습니다"

## 따라 하지 않는 것
- 실제 인물 사진·방송 화면: 저작권·초상권 문제 → 얼굴 없는 AI 사진으로 대신
- "화면을 두 번 누르면 정답 공개": 좋아요만 눌리고 답은 없는 낚시 → 답은 영상 안에서 알려 준다
- 이혼·사별·옛 연인 같은 사생활 주제 → 미담·기록·무명 시절로
