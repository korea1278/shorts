영화 짜깁기 쇼츠 제작기

원본 영상 올리기 → AI가 장면·대사 분석 → 제목·대본·편집점 → 자동 컷 편집 + 나레이션 + 자막 → 세로 영상

만들 버전

같은 영상이라도 두 버전은 대본·언어·목소리·고르는 장면·전개 순서·제목 색·글꼴·화면 움직임이 서로 다르게 만들어져서 재사용 콘텐츠로 겹쳐 보이지 않아요. 한 버전을 끝낸 뒤 탭을 바꾸고 "분석하고 대본 만들기"를 한 번 더 누르세요. (영상·자막·자르기는 그대로 써요)

API 키 · 목소리 설정

처음 누를 때 모델(약 400MB)을 받아요. 이후엔 바로 나와요.

PC방에서는 체크하지 마세요. 창을 닫으면 키가 지워져요.

고급 설정 (모델·소리 크기·화면)

1원본 영상 올리기

드라이브에 올려 둔 영화를 골라 불러와요. 전체 영화(mkv)도 돼요.
한국어 자막이 있으면 대사 받아쓰기 대신 써요 (무료, 더 정확)

전체 영화에서 구간 자르기

자막이 없으면 영화 전체 대사를 받아써서 골라요.
구글 드라이브 연결 설정 (이미 넣어 두었어요. 바꿀 때만 열기)

두 값은 설정 안내대로 구글 클라우드에서 만들어요. 내 도구 주소에서만 작동하게 제한되니 저장해도 괜찮아요. 값을 알려 주시면 도구 안에 미리 넣어 드릴 수도 있어요.

영상을 불러온 뒤 누르세요. 오른쪽 미리보기에서 원래 자막이 안 보이는지 확인하세요.
영상(또는 잘라 낸 구간)이 불러와지면 눌러져요.

2제목 · 대본 · 편집점 확인

분석이 끝나면 여기에 나와요.

썸네일을 누르면 그 장면이 미리보기에 나와요. 시작 시간(초)을 고치거나 ±버튼으로 장면을 옮길 수 있어요. 파란 번호는 나레이션을 멈추고 원본 대사를 크게 들려주는 장면이에요.

3영상 만들기

실제 길이만큼 재생하면서 녹화돼요. 녹화 중에는 이 탭을 화면에 띄워 두세요.
