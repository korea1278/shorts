# 레퍼런스 분석 (커뮤니티 썰 쇼츠 5편, 2026-10-08)

주제: 요새 149승 1패, 600년 전 SNS 말투(맹사성), 경찰도 인정한 비상 상황, 한국 잠수함·미사일, 한국 사계절과 K9.
크기는 1080x1920 기준.

## 화면
| 항목 | 레퍼런스 측정값 | 엔진 (`make_short.py`) |
|---|---|---|
| 배경 | 완전 검은색 | `BG` |
| 제목 | 맨 위 2줄, 아주 두꺼운 고딕, 글자 높이 약 95px, 테두리 없음. 한 줄 노랑 + 한 줄 흰색 | 프리텐다드 Black, 줄 중심 268/400px, `title_yellow`로 노란 줄 선택 |
| 그림 | 가운데 가로 꽉 참, 약 480~1440px (1080x960) | `IMG_TOP`, `IMG_H` |
| 그림 종류 | 이라스토야 같은 간단한 일러스트(흰 바탕), 밈 그림, 사진 | 이라스토야(20장까지) + AI 클립아트 |
| 그림 교체 | 약 1.6초마다 (느린 영상 3.5초) | 장면당 1~2장 |
| 자막 | 그림 아래쪽 안, 검은 상자 + 노란 글자(대사는 흰색·따옴표), 글자 높이 약 45px, 한 줄 | 프리텐다드 ExtraBold, 중심 1362px, 12자 |
| 강조 | 빨간 글자 (전부 사망, 전멸 당함) | 장면 `red` |
| 시작 | 어두운 게시판 목록에서 해당 글에 커서 → 클릭 (약 2초) | 첫 장면 `"board"` |
| 끝 | 구독 부탁 없이 웃음 포인트에서 바로 끝 | 마지막 0.35초 뒤 끝 |

## 소리
| 항목 | 레퍼런스 측정값 | 엔진 |
|---|---|---|
| 목소리 | 젊은 남성 1명, 억양 큼 (질문 약 220Hz, 시큰둥한 대답 약 95Hz) | Hojin Lim, stability 0.3 · style 0.45 |
| 빠르기 | 1초에 약 6.6글자 (공백 제외) | speed 1.15 + 쉼 줄이기 → 약 6.7글자 |
| 쉼 | 거의 0초, 웃음 포인트 앞만 0.3~0.5초 | `max_pause` 0.12초, 장면 `pause` |
| 배경음악 | 가볍고 경쾌, 목소리보다 약 8~10dB 작게 | `bgm/` 파일 또는 직접 만든 기타 반주 |
| 효과음 | 4~5초마다, 웃음 포인트에 | 장면 `sfx`: pop, ding, boing, whoosh, dundun, fail |
| 최종 음량 | - | -14 LUFS |

## 대본
- 37~57초, 공백 제외 260~320자
- 음슴체("~했음", "~함", "~거임") + 대화체
- 제목 = 궁금증 한 줄 → 상황 → 갈수록 세지는 전개 → 반전·웃음 포인트로 끝

## 따라 하지 않는 것
- 페페 개구리 등 남의 캐릭터·밈 그림
- 실제 커뮤니티 글 캡처(닉네임 포함), 원문 그대로 읽기
- 사이트 이름·로고가 보이는 게시판 화면

  빠르기는 1초에 약 6.1글자로 레퍼런스(6.6)보다 조금 느리다
