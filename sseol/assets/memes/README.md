# 밈 그림 폴더

여기에 넣은 그림을 대본에서 `{"meme": "파일 이름"}` 으로 씁니다 (확장자 빼고).
png · jpg · webp · gif(첫 장면만) 모두 됩니다.

GitHub에서 넣는 법: 이 폴더 열기 → **Add file → Upload files** → 그림 끌어다 놓기 → **Commit changes**

추천 파일 이름 (이름만 맞추면 클로드가 상황에 맞게 골라 씁니다)

| 파일 이름 | 쓰는 상황 |
|---|---|
| 페페눈물 | 억울·슬픔·현타 |
| huh고양이 | 어이없음·갸우뚱 |
| 기가차드 | 당당함·상남자 |
| 놀란고양이 | 충격·경악 |
| 웃는개 | 웃김·흐뭇 |
| 멍때림 | 정적·할 말 없음 |

- 파일이 없는 이름을 쓰면 우리 리액션 캐릭터 **햄찌**가 대신 나옵니다 (영상이 멈추지 않음).
- 밈 그림은 원작자 권리가 있어 저작권 신고(특히 수익 창출 채널)가 들어올 수 있습니다. 넣을 그림은 직접 골라 주세요.
